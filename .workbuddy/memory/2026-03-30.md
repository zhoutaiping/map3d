# 2026-03-30 地图纹理和散点图标修复日志

## 修复问题

### 1. scatter3D散点图标不生效问题
**问题表现**：根据stationType字段设置的图标不显示
**根本原因**：
- 中国地图模式调用createScatterSeries时未传递useCustomIcon: true参数
- 使用图片图标时设置了itemStyle.color，覆盖了图片本身的颜色

**修复方案**：
1. 中国地图模式添加useCustomIcon: true参数
2. 在createScatterSeries函数中，当useCustomIcon为true时将color设置为'transparent'

### 2. 地图纹理图片mapBgChina颜色被覆盖问题
**问题表现**：地图纹理不显示，地图省份显示默认颜色
**根本原因**：
- itemStyle.color属性覆盖了纹理颜色
- 使用ITEM_STYLE_TEXTURED常量后地图省份变为透明

**修复方案**：
1. 中国地图和大区地图的series配置中直接设置itemStyle为：
   ```
   itemStyle: {
     color: 'transparent',
     opacity: 1,
     borderWidth: 1,
     borderColor: "#ffffff",
   }
   ```
2. 移除对ITEM_STYLE_TEXTURED常量的依赖

## 下钻功能修复 (2026-03-30)
**问题表现**：下钻到大区后，点击返回全国地图，全国地图无法下钻到省份
**根本原因**：
- 从大区地图返回全国地图时，`chartInstance`的点击事件监听器被清理
- `renderChinaMap`函数中没有重新绑定点击事件，导致下钻功能失效

**修复方案**：
在`renderChinaMap`函数末尾添加事件绑定代码：
1. 清理旧的点击事件：`chartInstance.off('click')`
2. 重新绑定点击事件处理函数，包含：
   - 散点点击判断和阻止下钻
   - 省份下钻逻辑
   - 多级下钻支持

**修改位置**：`renderChinaMap`函数末尾，第518行之后

## 注意事项
- 当使用realisticMaterial时，地图省份显示为透明是预期行为
- 纹理应该覆盖整个地图表面，而不是显示省份颜色
- 如果需要同时显示省份颜色和纹理，需要重新设计材质配置
